# Walley skills

Standing checklists for Walley. Each folder holds a `SKILL.md`.

| Skill | Use when |
| --- | --- |
| `walley-tenant-scope-check` | Adding or changing a query, route or repository function that reads or writes user data |
| `walley-secrets-check` | Touching Wallos keys, Actual passwords, sync keys, encryption, logging, or any response with user config |
| `walley-qa-test-matrix` | Planning or reviewing tests for an issue or milestone |
| `walley-release-checklist` | Before a release, or when `package.json`, CI, env vars, the Dockerfile or migrations change |

The shared UI skills (`ui-*`) and `release-shipped-files-check` are user-level, in `~/.claude/skills/`. Their index is `~/.claude/skills/MAP.md`.
