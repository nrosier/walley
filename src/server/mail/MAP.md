# src/server/mail

Outgoing email for local registration (issue #99). Nothing here reads `process.env`; callers pass values from `AppConfig`.

| Path                                  | What it is                                                                                                                                                                                                                                                                                                                                                  | Read it when                              |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| `mailer.ts`                           | `Mailer` (`send({ to, subject, text })`, fire and forget, never throws), `createMailer({ transport, from, capacity?, log? })` with a bounded in-memory queue (`MAIL_QUEUE_CAPACITY`) that drops when full, and `createCapturingMailer()` for tests. Logs only the fixed lines `MAIL_DROPPED_LINE` and `MAIL_FAILED_LINE`, never an address, subject or body | Sending mail, or changing queue behaviour |
| `smtp.ts`                             | `createSmtpTransport(smtpUrl)`: nodemailer transport from `SMTP_URL`. The URL can hold credentials; never log it                                                                                                                                                                                                                                            | Changing the transport                    |
| `templates.ts`                        | `VERIFICATION_TOKEN_TTL_MS` (24 hours, owner decision), `buildVerificationLink` (`${origin}/verify-email#token=...`, fragment keeps the token out of logs and Referer), `verificationEmail`, `alreadyRegisteredEmail`                                                                                                                                       | Changing email wording or the link        |
| `index.ts`                            | Public exports                                                                                                                                                                                                                                                                                                                                              | Importing from outside this folder        |
| `mailer.test.ts`, `templates.test.ts` | Tests for overflow, failure isolation and templates                                                                                                                                                                                                                                                                                                         | Changing the files above                  |
