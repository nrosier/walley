# src/lib

- `amount-match.ts`: `amountWithinTolerance` (integer math on absolute values, larger-of-two base), `rangeMidpointCents` (half away from zero), `DEFAULT_TOLERANCE_PERCENT`.
- `amount-match.test.ts`: tests for `amount-match.ts`.
- `match-badge.ts`: `MATCH_BADGES` and `matchBadge` (status to label and tone), plus `pairBadge({status, orphan})` returning `PairBadgeKind` (`synced` | `mismatch` | `ignored` | `orphaned`); any non-null orphan wins.
- `match-badge.test.ts`: tests for `match-badge.ts`, including the `pairBadge` truth table.
- `match-fields.ts`: browser-safe canonical form of the compared fields (`normalizeMatchFields`, `serializeMatchFields`, `canonicalMatchString`); the name is trimmed, whitespace-collapsed and lowercased; null for pattern schedules. Hashed by `src/server/matching/hash.ts`.
- `match-fields.test.ts`: tests for `match-fields.ts`, including that it imports no Node built-ins.
- `name-match.ts`: `normalizeName`, `nameScore` (0..1 token overlap), `namesMatch`, with `LEGAL_SUFFIXES` and `NAME_MATCH_THRESHOLD`.
- `name-match.test.ts`: tests for `name-match.ts`.
- `auth-mode.ts`: auth method constants and the `isAuthMethod` guard.
- `auth-mode.test.ts`: tests for `auth-mode.ts`.
- `currency-convert.ts`: pure Wallos-rate conversion of integer minor units (`convertPriceCents(cents, fromRate, toRate, fromExponent = 2, toExponent = 2)`, rescaling between currencies with different minor units), rate parsing (`parseRate`), and override-over-Wallos rate selection (`selectRate`), plus `CurrencyConversionError`. No I/O.
- `currency-convert.test.ts`: tests for `currency-convert.ts`.
- `frequency-mapper.ts`: `wallosToActual` and `actualToWallos` frequency mapping, plus `FrequencyMappingError`.
- `frequency-mapper.test.ts`: tests for `frequency-mapper.ts`.
- `billing-cycle.ts`: `billingCycleOf(frequency, interval?)` (#136), the one mapping from an Actual frequency and interval (Wallos items arrive in that form too) to `{ key: monthly|yearly|weekly|custom_days, count }`, null when invalid. Used by `sync-check.ts` for unlinked items; browser-safe, no labels.
- `billing-cycle.test.ts`: tests for `billing-cycle.ts`.
- `sync-check-types.ts`: browser-safe response types of `POST /api/sync/check` (`SyncCheckResult`, `SyncItem`, `SyncCandidate`, `SyncMismatch`, `SyncUnmappable`, `SyncOrphaned`, `SyncLinked` (with `relinkCandidateIds`, the unlinked missing-side ids that pass the candidate rule for an orphaned row, best name score first), `SyncIgnored`, `SyncOrphanKind`, `UnmappableReason`). Types only; re-exported by `src/server/matching/sync-check.ts` for the web app.
- `match-status.ts`: match status constants and the `isMatchStatus` guard.
- `password-policy.ts`: `PASSWORD_MIN_CODE_POINTS` (15) and `PASSWORD_MAX_CODE_POINTS` (256), shared by `src/server/auth/passwords.ts` and the account form's `minLength`.
- `currency-exponent.ts`: `currencyExponent(code)` minor-unit digits per ISO code (0 for IRR, JPY, KRW; 2 otherwise, `DEFAULT_CURRENCY_EXPONENT`), from the @actual-app/api currency list.
- `currency-exponent.test.ts`: tests for `currency-exponent.ts`.
- `money.ts`: `toActualCents` (option `exponent`, default 2) and `fromActualCents(cents, exponent = 2)` conversions between decimals and Actual Budget integer minor units.
- `money.test.ts`: tests for `money.ts`.
- `format-money.ts`: `formatMoney(cents, currency, locale)` display formatter for integer cents via Intl (currency digits from Intl; keeps sign).
- `format-money.test.ts`: tests for `format-money.ts`.
- `smoke.test.ts`: test runner smoke test.
- `tsconfig.json`: TypeScript config for this directory.
